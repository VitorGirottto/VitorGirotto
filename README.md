# 🏰 Central de Desenvolvimento Medieval ⚔️

**Bem-vindo ao Reino dos Códigos Sagrados!**  
Este é um projeto web com temática medieval, criado para apresentar e organizar projetos estáticos como se fossem artefatos místicos. A estética é inspirada em castelos, pergaminhos e elementos visuais da era medieval.

---

## ✨ Visão Geral

A **Central de Desenvolvimento Medieval** é uma página HTML estilizada que serve como portfólio ou indexador de sites estáticos. Cada projeto é apresentado como uma "pasta do reino", com uma interface envolvente e interativa.

---

## ⚙️ Funcionalidades

- 👑 **Tela de carregamento temática** com castelo animado.
- 🕯️ **Elementos flutuantes** como tochas, espadas e escudos.
- 📜 **Introdução em estilo pergaminho** com letras iluminadas.
- 📁 **Grid de projetos** que simula um reino de pastas mágicas.
- 🧾 **Modal interativo** com detalhes sobre cada projeto:
  - Título
  - Descrição
  - Data
  - Arquivos
  - Acesso ao site ou repositório

---

## 🧪 Tecnologias Utilizadas

- HTML5
- CSS3 (com animações e customizações visuais)
- JavaScript puro (DOM manipulation)
- [Google Fonts](https://fonts.google.com/) (Cinzel, MedievalSharp, Uncial Antiqua)
- Emojis e SVG embutidos no favicon
